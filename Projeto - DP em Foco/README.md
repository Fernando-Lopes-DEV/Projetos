# 📊 DP em Foco – Página de Vendas  

  

## 📌 Sobre o Projeto  
O **DP em Foco** é uma página estática desenvolvida com **HTML e CSS** para a **venda de planilhas financeiras** voltadas para profissionais de Departamento Pessoal (DP).  

**A proposta é oferecer um site de vendas simples.**  

---

## 🎯 O que essa página oferece?  

✔ **Design moderno e responsivo**    
✔ **Fácil navegação e experiência intuitiva para o usuário**  

---

## 🛠️ Tecnologias Utilizadas  

| Tecnologia | Descrição |
|------------|-----------|
| **HTML5** | Estruturação da página |
| **CSS3** | Estilização responsiva e atraente |
| **Google Fonts** | Fontes personalizadas para melhor leitura |
